---
name: 管理者の初期設定
description: 公開時の管理者パスワード設定と、初回アクセスによるアカウント乗っ取りの防止
---

管理用パスワードはSecretsのADMIN_PASSWORDから指定し、公開環境では認証なしの初回パスワード設定を許可しない。開発時の初回設定画面は補助機能としてのみ残す。

**Why:** 開発DBと公開DBのデータは同一とは限らない。公開DBが空のとき、最初にアクセスした第三者が管理者パスワードを設定できる設計は危険なため。

**How to apply:** 公開の準備ではADMIN_PASSWORDとSESSION_SECRETの存在だけを安全な設定ツールで確認する。値をチャット・ログへ出力しない。秘密情報をメモリへ保存しない。
